# 安装指南

## 系统要求

- Windows 7 或更高版本
- Excel 2010+ 或 WPS Office（Windows 版）
- 32 位或 64 位 Office（需下载对应位数的 XLL）

## 下载

从 [Releases](../../releases) 页面下载对应版本的 `.xll` 文件：

| 你的 Office 类型 | 下载文件 |
|------------------|----------|
| 64 位 Excel | `rust_sqlite.xll`（x64） |
| 32 位 Excel / WPS | `rust_sqlite.xll`（x86） |

> 如何判断 Office 位数？Excel → 文件 → 账户 → 关于 Excel，查看是否包含 "64 位"。

## 安装步骤

### Excel

1. 打开 Excel，点击 **文件 → 选项 → 加载项**
2. 底部 **管理** 下拉框选择 **Excel 加载项**，点击 **转到**
3. 点击 **浏览**，选择下载的 `rust_sqlite.xll`
4. 勾选 **rust_sqlite**，点击 **确定**
5. 重启 Excel

### WPS

1. 打开 WPS 表格，点击 **开发工具 → 加载项**
2. 点击 **浏览**，选择下载的 `rust_sqlite.xll`
3. 勾选并确定，重启 WPS

> 如果看不到 "开发工具" 选项卡：WPS → 选项 → 自定义功能区 → 勾选 "开发工具"。

## 验证安装

在任意单元格输入：
```excel
=SqlVersion()
```

如果返回类似 `3.45.1` 的版本号，说明安装成功。

## 卸载 / 更新

1. Excel → 文件 → 选项 → 加载项 → 转到
2. 取消勾选 **rust_sqlite**，点击 **确定**
3. 关闭 Excel，确保进程完全退出（任务管理器检查 `EXCEL.EXE`）
4. 删除旧的 `.xll` 文件，重新安装新版本

> **重要**：更新前务必取消勾选旧加载项并完全退出 Excel，否则文件被占用无法覆盖。

## 常见问题

### "无法加载加载项" 或 "文件格式无效"

- 确认下载的 XLL 位数与 Office 位数一致（32 位 Office 不能加载 64 位 XLL）
- 尝试以管理员身份运行 Excel 后重新加载

### WPS 提示 "未安装 VBA 支持"

- WPS 个人版默认不带 VBA，需要安装 VBA 组件或切换到 WPS 专业版/企业版
- 或者使用 64 位 WPS + 对应 XLL（部分 WPS 版本仍使用 32 位）
